# Task Tracker API

**Серверное приложение для трекера задач сотрудников** на Django REST Framework с Docker-контейнеризацией.

### **Основная функциональность**
* Полный CRUD для сотрудников и задач
* Специальные эндпоинты для аналитики загрузки
* Валидация данных (дедлайны, статусы, зависимости)
* Автоматическая документация API (Swagger/ReDoc)
* Контейнеризация с Docker и Docker Compose
* Тестирование с покрытием >90%
* Пагинация, фильтрация и сортировка

### **Технические требования**
- **Python 3.11** + **Django** + **Django REST Framework**
- **PostgreSQL** в Docker-контейнере
- **Docker** + **docker-compose** для контейнеризации
- **Валидация данных** (проверка дедлайнов, статусов)
- **Автодокументация API** через Swagger/ReDoc (`/swagger/`, `/redoc/`)
- **Тестирование** — покрытие >90%
- **PEP8** — код соответствует стандартам
- **Git** — код хранится в удаленном репозитории

## 1. Модель `Employee` (Сотрудник)

### Основные поля

| Поле | Тип | Описание |
|------|-----|---------|
| `id` | `Integer` |Уникальный идентификатор |
| `first_name` | `CharField(150)` | Имя сотрудника |
| `last_name` | `CharField(150)` | Фамилия сотрудника |
| `middle_name` | `CharField(150)` |Отчество (опционально) |
| `position` | `CharField(200)` |Должность |

### Вычисляемые поля

- **`full_name`** (`property`)  
  Формат: *"Фамилия Имя Отчество"*

### Методы

- **`__str__()`**  
  Возвращает: *"Фамилия Имя — Должность"*

## 2. Модель `Tasks` (Задача)

### Основные поля

| Поле | Тип | Описание |
|------|-----|---------|
| `id` | `Integer` | Уникальный идентификатор |
| `title` | `CharField(100)` | Название задачи |
| `parent_task` | `ForeignKey(self)` | Родительская задача |
| `assignee` | `ForeignKey(Employee)` | Исполнитель |
| `deadline` | `DateTimeField` | Срок выполнения |
| `status` | `CharField` | Статус задачи |
| `created_at` | `DateTimeField` | Дата создания |

### Допустимые статусы (`status`)

- `inactive` — не активна *(по умолчанию)*
- `active` — в работе
- `complete` — выполнена

### Связи

- **`subtasks`** (`related_name`)  
  Коллекция дочерних задач
- **`assignee`**  
  Связь с исполнителем (`Employee`)

## 3. Правила валидации

* Дедлайн не может быть в прошлом
* Активная задача должна иметь исполнителя
* Проверка циклических зависимостей

## Запуск

### Предварительные требования
*   Docker и Docker Compose (рекомендуется)
*   Python 3.11+ (для локальной разработки)

### Запуск через Docker (рекомендуемый способ)
```
# 1. Клонирование репозитория
git clone https://github.com/kveremyeva/task-tracker.git
cd task-tracker

# 2. Копирование конфигурационного файла
cp .env.example .env
# При необходимости отредактируйте .env файл

# 3. Запуск приложения
docker-compose up --build

# 4. Приложение будет доступно по адресу:
#    http://localhost:8000/
```
